# Aadi — Interactive Portfolio

A personal portfolio for Agastya Tomar, built with React, TypeScript, Vite and Framer Motion.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## GitHub Pages
The included GitHub Actions workflow builds and deploys the site whenever code is pushed to `main`.

After the first successful workflow, open **Settings → Pages** and ensure the source is set to **GitHub Actions**.

## Personalize
Update project links, social profiles and contact email in `src/App.tsx`.
